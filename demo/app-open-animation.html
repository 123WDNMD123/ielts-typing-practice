📱 iOS 式「打开 App」动画

在网页里复刻手机系统的图标放大展开动画：图标从网格位置连续变形为全屏界面，壁纸同步推近虚化，其余图标退场；关闭时原路收回。纯前端单文件，零依赖。

实现方式

-- fps

操作

点击图标 打开 App
点击底部白条 / 上滑 / Esc 关闭
试试「计算器」，真的能算；「设置」开关可点。

原理

FLIP 模式：克隆被点图标为 position:absolute 飞行层，用 Web Animations API 把 left/top/width/height/border-radius 从图标矩形插值到全屏矩形；壁纸推近、图标退场全部走 transform/opacity 合成层。虚化是预模糊双层切换 opacity，不动画 blur 滤镜本身。

VT 模式：浏览器原生 document.startViewTransition() + view-transition-name 共享元素变形（Chrome 111+ / Safari 18.2+），其余层仍用 CSS 过渡。两种模式可切换对比。
